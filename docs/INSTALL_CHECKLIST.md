## Epic Games Launcher

- [x] Confermare UAC e installare il Launcher.
- [x] Effettuare il login Epic.
- [x] Installare Unreal Engine 5.8 in `C:\Program Files\Epic Games\UE_5.8`.
- [ ] In Options mantenere Templates and Feature Packs e Starter Content.
- [ ] Non installare inizialmente Android, iOS, Linux, debug symbols o editor symbols.
- [ ] Impostare Fab/Vault Cache su `D:\EpicVaultCache`.

## Visual Studio Community 2026

La Community e gratuita per uso individuale. UE 5.8 raccomanda Visual Studio 2026 per lo sviluppo generale.

- [ ] Installare Visual Studio Community 2026.
- [ ] Importare `config/OrbitalGlassLab.vsconfig`.
- [ ] Preferire un percorso su `D:` e non conservare il layout/cache di download dopo l'installazione.
- [ ] Verificare C++ Game Development, Unreal Tools, Blueprint Debugger, Test Adapter, HLSL Tools e Windows 11 SDK.
